# Card Engine

[![Maven Build & Test](https://github.com/nxckywhxte/card-engine/actions/workflows/maven-build.yml/badge.svg)](https://github.com/nxckywhxte/card-engine/actions/workflows/maven-build.yml)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

**Card Engine** — это профессиональный, универсальный headless-фреймворк на Java 25 для разработки классических карточных игр. От «Дурака» и «Покера» до «Бриджа» и кастомных авторских игр.

## 🎯 Философия проекта

В ядре движка находятся **только те абстракции, которые есть в ЛЮБОЙ карточной игре** (игрок, сущность, зона, действие, событие, состояние, контекст).

Мы не навязываем предметную область. В ядре нет жестко заданных классов `Card`, `Suit` или `Rank`. Вы сами решаете, что такое «карта», «масть» и «козырь», а движок берет на себя всю инфраструктурную рутину: сеть, сохранение, мультиплеер и защиту от читерства.

## ✨ Ключевые возможности

- 🧩 **Абстрактное ядро** — 7 базовых интерфейсов. Полная свобода в определении правил и сущностей.
- ⚙️ **Продвинутая FSM** — иерархические и параллельные состояния, стек действий, таймеры.
- 🌐 **Сетевой слой на Netty** + Java 25 Virtual Threads для тысяч одновременных партий.
- 🔒 **State Projections (Zero-Trust)** — клиент физически не получает данные, которые не должен видеть (античит из коробки).
- 📼 **Event Sourcing** — полное логирование, восстановление после сбоев, система реплеев.
- 🧪 **Встроенный фреймворк тестирования** и CLI-клиент для отладки.
- 📦 **Модульная архитектура** (Maven multi-module) — подключайте только то, что нужно.

## 🏗️ Архитектура и Модули

Проект разделен на 6 независимых модулей:

| Модуль | Описание |
| :--- | :--- |
| `engine-core` | Фундамент. 7 базовых интерфейсов, атрибуты, видимость зон. |
| `engine-fsm` | Машина состояний, игровой цикл, валидация действий, таймеры. |
| `engine-network` | Сетевой слой на Netty, State Projections, управление сессиями. |
| `engine-persistence` | Event Sourcing, снапшоты, восстановление игр, реплеи. |
| `engine-testing` | Утилиты для модульного тестирования игр и CLI-клиент. |
| `engine-api` | Фасад `GameBuilder` для удобной инициализации игры разработчиком. |

## 🛠️ Стек технологий

- **Java 25** (Records, Sealed Interfaces, Pattern Matching, Virtual Threads)
- **Maven** (Multi-module project)
- **Netty** (Высокопроизводительный сетевой фреймворк)
- **JUnit 5** (Тестирование)
